基于上海截至**2026年5月**生效的最新官方规定，以下为上海地区月薪1万、1.3万、1.5万元，社保基数统一按1万元、公积金比例5%计算的企业用人成本及员工到手工资明细。

**计算依据**

- 社保缴费基数：10,000元（企业及个人均以此基数计算）
- 公积金比例：5%（企业及个人各5%，基数同为10,000元）
- 社保企业缴纳比例：养老16% + 医疗9% + 失业0.5% + 工伤0.16% = 25.66% → 2,566元
- 社保个人缴纳比例：养老8% + 医疗2% + 失业0.5% = 10.5% → 1,050元
- 公积金企业：10,000 × 5% = 500元；公积金个人：500元
- 个税计算：应纳税所得额 = 税前月薪 − 5,000（起征点） − 1,050 − 500，适用3%税率（因均未超过36,000元）

**说明**

- 月总用人成本 = 员工税前工资 + 企业社保 + 企业公积金
- 员工月到手工资 = 税前工资 − 个人社保 − 个人公积金 − 个税
- 个税计算未考虑专项附加扣除，实际可能略有差异
